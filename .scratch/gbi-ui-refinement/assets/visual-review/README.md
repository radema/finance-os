Production UI screenshots used Vite against the local server and an isolated sample database in `/tmp/gbi-bauhaus-production`; there is no variant query. The empty first-run screenshot used `/tmp/gbi-empty-visual`. The long-label case is a separate copy with a synthetic long retirement name and a €999,999,999.99 target. The 60-month fixture is generated by `server/monthlyFixture.ts` in `/tmp/gbi-five-year`; one extra synthetic product was added during the successful retry test. No personal data was used.

## Findings and checks performed

- Representative images viewed directly include Overview at 1024 dark and 1440 light, Goal detail and Optimizer at 1440 light, Cash flow at 1024 light, and Allocation at 1920 dark. The sidebar labels align with their icons in the refreshed images. The long-name/large-value fixture initially exposed split KPI text and overlapping or clipped fan and histogram labels; the after and ordinary-viewport images show the corrected result at 1024 light.
- A full-page screenshot can put the Goal detail value-series end label over the left axis tick. This was reproduced during capture; a 1 px viewport resize restores the end label to the right in the ordinary viewport, shown in the value-chart image. This capture anomaly remains visible in full-page images and should not be read as the ordinary resized view.
- At 1024 × 768, all expanded sidebar links ended by y=698. Collapse moved the main content to x=0, persisted through reload, and restored. A Goal detail glossary control opened by Enter with `aria-expanded=true`; a card collapsed. Cash flow's Year cell remained at the wrapper's left edge after 100 px horizontal scrolling, and its header and Year cell computed as sticky.
- All eight Import tabs were visited, including file pickers and current portfolio. A synthetic transaction deletion confirmation opened and was cancelled. The empty database first-run Overview rendered its setup steps and sample-data action.
- Browser request interception produced an Overview failure and its retry restored the chart screen. A Products table failure showed Try again and restored its rows on retry. A product form save failure showed an error and retained the four typed values; retry succeeded in the scratch database. A temporary browser-only fetch delay showed Products table and Overview loading states, followed by successful rendering.
- In forced colours, a temporary specimen showed native `appearance: auto` for unchecked, checked, indeterminate, disabled unchecked and disabled checked states. Label activation and Space toggled an enabled checkbox; Tab and Shift+Tab moved focus with a solid outline; clicking disabled labels left both disabled states unchanged. Forced-colour Overview retained status words and active navigation; decorative motifs computed `display: none`.
- Final built production Overview, warmed on the 60-month fixture: last API response 317.2 ms and four block headings plus chart followed by two animation frames at 327.8 ms in one observed run, within AC-77's 2-second budget. This is a single local measurement, not a statistical benchmark.

Additional import, optimizer and pension workflow evidence is in [browser-workflows.md](browser-workflows.md). Overview screenshots were refreshed after the spacing correction; [measurements](matrix-overview-recapture.json) show a 48 px Goals-to-Plan gap at all three widths in both themes.

## Remaining approval and limitations

The authorized browser pass is documented across the tracks above. It covers the supported
screen/viewport/theme matrix and representative actual component/workflow states, rather
than every possible financial input or every combination of controls. Reports preserve
the exact checks and their limits; computed sticky positioning is supplemented by actual
Cash flow header/Year scrolling, not a scroll test of every repeated table instance.
Long/large Goal detail values were checked at 1024 light; ordinary sample negative values
were checked in Overview and appear in the theme matrix. The single Overview timing
measurement is not a statistical benchmark.

Human all-screen visual approval remains required. The full gate remains blocked by
optimizer timing failures and seven dependency audit advisories; see [automated checks](automated-checks.md).
The documented full-page Value-label capture anomaly remains a tooling limitation with
ordinary viewport evidence supplied. No merge readiness or human approval is claimed.
