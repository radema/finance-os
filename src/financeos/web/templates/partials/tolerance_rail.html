{# =========================================================================== CONTRACT 1 — THE TOLERANCE RAIL (UX-0001 §4.1) =========================================================================== A calibrated scale spanning −3…+3 band-widths, graduated at every whole band-width, with the in-tolerance zone shaded, the target as the centre tick, the current position as an index marker, and overflow past ±3 pinned against a hard stop with a caret. signed_severity = drift / effective_band position% = clamp(3, 97, 50 + (signed_severity / 6) × 100) WHY THIS WORKS AT ALL: severity is dimensionless (RFC-0007 §3.1), so ONE gauge is legible across every asset class and both tolerance kinds. A 6.00pp breach on a 40% ABSOLUTE target and a 0.5pp breach on a 2% RELATIVE target render comparably — that is the whole point of the severity contract, and a gauge keyed to raw drift would silently discard it. INVARIANT: this file is included UNCHANGED on findings, the explanation surface, allocation and strategy authoring. Three geometries in three places means the contract is lost. Do not fork it; extend it here. --------------------------------------------------------------------------- INTERFACE — what a screen must pass --------------------------------------------------------------------------- signed_severity Decimal|float|None drift / effective_band, SIGNED. None => the unbanded state (a legal null severity, RFC-0008 §3 sorts NULLS LAST deliberately). target_label str e.g. "target 40,00%". Rendered under the centre tick. Already formatted it-IT by the caller. aria_label str REQUIRED. A full sentence carrying the same fact in words, because the gauge is an image. e.g. "Equity/Developed a 34,00% contro un target di 40,00%, tolleranza ±2,00pp: 3 ampiezze di banda sotto il target." breach bool optional; defaults to |signed_severity| > 1. --------------------------------------------------------------------------- The caller passes signed_severity; this partial does the clamp so the formula lives in exactly one place. #} {%- set sev = signed_severity -%} {%- set unbanded = sev is none -%} {%- if not unbanded -%} {%- set raw = 50.0 + (sev | float / 6.0) * 100.0 -%} {%- set pos = [[raw, 3.0] | max, 97.0] | min -%} {%- set is_breach = breach if breach is defined and breach is not none else (sev | float | abs > 1.0) -%} {%- set clamped_low = raw < 3.0 -%} {%- set clamped_high = raw > 97.0 -%} {%- endif -%}
