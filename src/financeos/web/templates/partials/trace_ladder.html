NEVER prose. This follows RFC-0009 §4.1: the trace is DATA with ordered steps, precisely so the explanation can be mechanical rather than interpretive. Rendering it as a sentence throws that away. TWO RULES THIS FILE ENFORCES, AND A SCREEN MUST NOT UNDO --------------------------------------------------------------------------- 1. Every binding's `source` is a link WHEREVER IT RESOLVES. The chain Recommendation → trace → Rule → StrategyVersion → your own change_note must be walkable by clicking, not by querying. That chain IS P7. 2. DECIMALS RENDER EXACTLY AS STORED, AS STRINGS. Never format a trace value through a float and never apply a number filter to one. Pass `value` and `result` as the strings the trace holds. There is deliberately no formatting filter applied below — if you add one you have broken the replay guarantee this surface exists to demonstrate. The it-IT display formatting of ADR-L03 §5.2 applies to the OBSERVATION, never to the trace. STAGING — the held moment: the derivation is frozen at the step where the condition became true. That terminal step is emphasised as the held step; every step above it reads as an already-established premise, and each one's intermediate result stays visible rather than hiding behind a hover. --------------------------------------------------------------------------- INTERFACE — what a screen must pass --------------------------------------------------------------------------- bindings list[dict] ordered. Each: name str binding name, English identifier, as stored value str THE STORED STRING. Not a Decimal, not a float. source str human-readable source, e.g. "strategy_version sv:1f2c… · targets.EQUITY.DEVELOPED" source_url str|None where it resolves. None => derived by an engine, rendered as plain text, never as a dead link. steps list[dict] ordered. Each: ordinal int|str the step number as stored op str the operation name, e.g. "divide_safe" operands str operand expression, as stored result str THE STORED STRING, e.g. "current_weight = 0.3400" held bool optional; true on the terminal/breaking step.
