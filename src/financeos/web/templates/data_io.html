Operazioni ADR-0026, ADR-0028, ADR-L01

Un file CSV con colonne account_id,asset_id,type,trade_date,quantity,price,fees,currency,ref. Ogni riga diventa una o più Operation nello stesso lotto di importazione; il registro resta append-only, quindi una rettifica va importata come una nuova riga CORRECTION, mai come una modifica.

Strategia ADR-0027

Un file YAML canonico di Strategy. Se lo strategy_id è già presente, l'importazione congela una nuova versione della stessa strategia — non ne esiste una modificabile in-place — e richiede comunque una change_note nel file stesso.

Esporta dati authored RFC-0009 §7.1

L'unico percorso di recupero per apportionment e Strategy: dati che non possono essere ricostruiti dai raw importati, a differenza di Operation e prezzi. Il download è un archivio zip con un file per la storia di apportionment di ciascun Bucket, un file per ogni versione congelata di ogni Strategy, e un file per le classificazioni correnti degli asset.
