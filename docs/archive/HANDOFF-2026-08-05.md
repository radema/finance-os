## 5. Dead ends — tried and failed

- **Freezing `Asset.asset_class`** is not available. ADR-0012 makes it "mutable in place under the
  correction model" (`asset.py:5`); the corpus outranks the code, so the option does not exist.
- **Folding `asset_classification_audit` into the generic table** — rejected: corpus DDL with a named
  reader and a `reason` column the others do not need. Needs an RFC amendment, which is not a build
  decision.
- **Double-writing class changes into both tables** (option B) — rejected: stores one fact twice.
- **Adding `is_archived` / delete-when-unreferenced** — rejected twice now (ticket 01, then ticket 02):
  a column plus a filter on every read-side account/asset query.
- **Duplicating entity current state into `export --authored`** — rejected: the full backup already
  round-trips it, and two recovery paths can disagree.
- **A `stale` flag on `Alert`, or re-running past `EvaluationRun`s after an edit** — rejected: mutates
  immutable audit artifacts, and the stored trace already satisfies I-6.

## 11. Gotchas

- The `PreToolUse` hook **denies `find`/`cat`/`head`/`tail`/`sed` with a file operand**. It kills the
  whole compound command, so a `cat >> file <<EOF` heredoc followed by a `sed -i` on the next line
  writes *nothing*. Append with the heredoc alone, then use `Edit`. Cost one wasted round-trip today.
- Bash cwd persists between calls but a denied command's `cd` does not run — re-`cd` after a denial.
- `demo/expected/` asserts exact numbers, so the `assets.csv` `identifiers` column ticket 02 folded in
  is not a one-file change: `csv_backup.py`, `demo/assets.csv`, `demo/expected/`, and the seed importer.
- Ticket 05's answer is **desk research only** — no real file was ever opened, encodings unconfirmed
  for all nine providers. That is precisely why ticket 19 exists; do not treat 05 as ground truth about
  a specific bank's file.
- The map is an **index, not a store**. A decision lives in its ticket; the map only gists and links.
  Resist restating ticket detail there.
